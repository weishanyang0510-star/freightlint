# FreightLint · 货运表格检查

一个给小型物流团队和导入工具开发者使用的开源 CSV 检查工具。检查重复运单、漏填字段、无效件数/重量/体积及日期问题。中英文表头共用同一套规则，文件在本机内存中处理。

这是刚起步的独立项目，尚无经过验证的生产用户或下载量，不代表任何物流公司。全部示例都是虚构数据，未使用雇主代码、内部模板或客户数据。开发过程由 OpenAI Codex 辅助。

## 直接使用

[在线打开检查工具](https://weishanyang0510-star.github.io/freightlint/)，也可以下载后离线使用。

1. 在 GitHub 点击 Code → Download ZIP，解压后双击 `index.html`。
2. 点击「试试问题示例」查看结果，或选择自己的 UTF-8 CSV 文件。
3. 按行号修改原文件，再检查一次。可以下载问题 CSV 或完整 JSON 报告。

不需要安装、不需要账户、不需要 API，不产生运行费用。下载完整文件后可离线使用。浏览器与命令行使用相同的检查引擎。

## 数据格式

**每行是一票运单或一个分单，不是一个商品明细。** 同一运单下的不同分单用不同的 `分单号`。商品明细请先按运单/分单汇总。

| 中文表头 | 英文字段 | 规则 |
| --- | --- | --- |
| 运单号 / 订单号 | order_id | 必填，保留前导零，区分大小写 |
| 分单号 | split_id | 可选；重复运单号下必须有不同分单号 |
| 起运地 / 始发地 | origin | 必填 |
| 目的地 | destination | 必填 |
| 件数 | pieces | 正整数 |
| 重量kg / 毛重kg | weight_kg | 大于零的十进制数，单位 kg |
| 体积cbm | volume_cbm | 大于零的十进制数，单位 m³ |
| 运输方式 | mode | 可选；空运、海运、陆运、铁路、多式联运 |
| 预计出发日期 | etd | 可选，YYYY-MM-DD |
| 预计到达日期 | eta | 可选，YYYY-MM-DD，不早于出发日期 |

支持 UTF-8/BOM、逗号/分号/Tab、标准双引号、带换行的引号字段。每份文件最多 5 MiB、10,000 行。页面最多显示 500 条筛选结果，下载报告包含全部问题。Excel 请先另存为 CSV UTF-8；暂不直接读取 XLSX，也不自动换算单位。

错误阻止基础校验通过；提醒需要人工确认。行号是原始文本的物理行号，0 表示整个文件。检查通过不代表承运人已接受货物，也不核验地址真实性、报关、危险品、价格或运价。

## 命令行与贡献

Node.js 20 或以上，无需安装依赖：

```sh
node bin/freightlint.cjs examples/valid.csv
node bin/freightlint.cjs examples/issues.csv --json
node --test
```

退出码：0 = 无错误；1 = 有校验错误（加 `--strict` 时提醒也返回 1）；2 = 文件、编码或参数错误。

工具没有分析埋点、服务器上传、外部字体或持久化存储。报告可能含原始单号和字段值，应按业务数据保管。提交 issue 时请只使用虚构或脱敏示例。贡献说明见 [CONTRIBUTING.md](CONTRIBUTING.md)，规则细节见 [docs/rules.md](docs/rules.md)。MIT 许可。
